PureCut Lab (v1.0.0) (Local Dev Only)

why is this a local page?

Because the model runs on your machine, not in this tab. The PureCut studio is a pure client-side app and stays that way — its models run inside the browser through WebAssembly and WebGPU. RMBG-2.0 cannot join them: its ONNX export fails at session creation under onnxruntime-web (ShapeInferenceError: inferred=4 declared=6), and the browser's WASM build hardcodes strict shape inference, so no flag or setting works around it. The very same file loads fine under onnxruntime-node.

So this page is only a control panel. It talks to a small Node process on your computer, which loads the checkpoint natively and does the actual inference. The tab you are looking at performs no model work at all — that is why it stays responsive while a run is going. Nothing is uploaded anywhere; the only network traffic is the one-time checkpoint download from Hugging Face.
