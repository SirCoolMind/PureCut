PureCut × Bria RMBG-2.0

dev only

Upload images, choose a checkpoint, and run the real RMBG-2.0 on your machine. This route exists only while npm run dev (or npm run rmbg2:lab) is running — it is not in the production build, and it only answers requests from this computer.

Why is this a local page and not the app itself? RMBG-2.0 cannot load in a browser tab. Its ONNX export fails at session creation in onnxruntime-web (ShapeInferenceError: inferred=4 declared=6), and the WASM build hardcodes strict shape inference, so no setting works around it. The same file loads fine under onnxruntime-node — which is what this page drives through a local child process. The PureCut studio still ships only browser-capable models.
